# Contributing to CampusFlow

This is a learning portfolio project. Try these improvements and document your changes in commits.

1. Run the project and reproduce its documented behavior.
2. Choose one meaningful change you can explain (a tested feature, accessibility fix, or validation improvement).
3. Add or update tests for your change.
4. Update the README with real screenshots once you personally verify the interface.
5. Do not commit passwords, private student records, personal data, or generated secrets.

The project started with AI assistance. Explain your own contributions accurately in academic applications.
